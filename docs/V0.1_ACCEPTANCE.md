# v0.1 live acceptance checklist

Run these tests on a disposable TIA Portal V21 project before using the MCP on a production project.

## Environment

1. Install TIA Portal V21 + Openness.
2. Add the Windows user to `Siemens TIA Openness` and sign out/in.
3. Build with `scripts/build.ps1`.
4. Open exactly one V21 test project in TIA Portal.
5. Run `TiaAgent.Host.exe doctor`.

## Read-only acceptance

Start:

```powershell
TiaAgent.Host.exe --access inspect
```

Verify from an MCP client:

- `get_project_status` returns the correct PID/path.
- `browse_project_tree` returns the expected PLC and deterministic block paths.
- SCL blocks include `author/version/family` when TIA exposes them.
- `get_block_source` returns `.scl` or `.db` content and a stable SHA-256 across two reads.
- `compile`, `preview_block_update`, and `apply_block_update` are not discoverable.

## Engineering acceptance

Start:

```powershell
TiaAgent.Host.exe --access engineering
```

Use a small SCL test FB.

### Successful edit

1. Read the block.
2. Preview a harmless comment/logic change.
3. Apply with the returned token/hash and `saveAfterSuccess=false`.
4. Confirm compile reports 0 errors.
5. Confirm the TIA project shows the edit but is not automatically saved.
6. Re-read source and confirm returned hash matches the re-exported project state.

### Concurrency rejection

1. Preview an edit.
2. Manually modify the same block in TIA Portal.
3. Call apply using the old hash/token.
4. Confirm `concurrency_conflict` and no MCP write occurs.

### Compile failure + rollback

1. Preview source containing a deliberate SCL compile error.
2. Apply.
3. Confirm `compile_failed`.
4. Confirm `rollbackAttempted=true`.
5. Confirm the original source is restored and compiles.
6. Confirm the project was not saved by the failed operation.

## Current known limits

- V21 only.
- PLC-scoped blocks only; Software Units are not yet supported.
- SCL FB/FC/OB and GlobalDB external source only.
- No project open/close/create lifecycle tools yet.
- No PLC download, online diagnostics, RUN/STOP, Safety, HMI, Startdrive, LAD/FBD writes.
- Live validation is mandatory because Siemens Openness behavior can differ by installed product/options and project type.
